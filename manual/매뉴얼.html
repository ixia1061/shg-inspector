설치 가이드

휴대폰·PC에 설치하고 로그인하기

앱스토어에서 내려받는 앱이 아니라, 인터넷 주소로 접속한 뒤 “홈 화면에 추가”하면 앱처럼 쓰는 방식(PWA)입니다. 설치 파일(.exe·.apk)이 없습니다.

1접속 주소 (공통)

컴퓨터·휴대폰 모두 같은 주소를 사용합니다.

https://shg-inspector.vercel.app

참고관리 업무(등록·통계·인쇄)는 PC, 현장 점검은 휴대폰이 편리합니다. 관리자 계정은 시스템관리자가 발급하고, 점검자는 사업장 가입코드로 직접 가입 신청한 뒤 관리자 승인을 받습니다.

2안드로이드에 설치

  1. 크롬(Chrome) 앱을 열고 위 주소로 이동합니다.
  2. 오른쪽 위 점 3개(⋮) 메뉴를 누릅니다.
  3. [앱 설치] 또는 [홈 화면에 추가] → [설치].
  4. 홈 화면에 소화기점검 아이콘이 생깁니다.

3아이폰·아이패드에 설치

  1. 사파리(Safari) 앱을 열고 위 주소로 이동합니다. (크롬이 아닌 사파리)
  2. 아래 가운데 공유 버튼(□↑)을 누릅니다.
  3. 메뉴를 내려 [홈 화면에 추가] → [추가].

주의아이폰은 반드시 사파리에서 “홈 화면에 추가”를 해야 카메라(QR 스캔)와 오프라인 기능이 정상 동작합니다.

4윈도우 PC에 설치

  1. 크롬 또는 엣지로 위 주소에 접속합니다.
  2. 주소창 오른쪽 끝의 설치 아이콘(⊞)을 누릅니다. (안 보이면 점 3개 → 앱 → 이 사이트를 앱으로 설치)
  3. [설치]를 누르면 바탕화면·시작 메뉴에 아이콘이 생깁니다.

팁설치하지 않고 브라우저 주소로 접속해도 모든 기능이 동일합니다. 설치는 “바로가기”를 만드는 것에 가깝습니다.

5처음 로그인 · 가입 신청

  1. 설치한 아이콘(또는 주소)으로 접속합니다.
  2. 이메일·비밀번호를 입력하고 [로그인].
  3. 역할에 따라 화면이 자동으로 나뉩니다 — 관리자 → 대시보드, 점검자 → QR 스캔.

점검자 계정이 없다면 (가입 신청)

  1. 관리자에게 우리 사업장의 가입코드(영문·숫자 4자리)를 받습니다.
  2. 로그인 화면 아래 [점검자이신가요? 가입 신청] 을 누릅니다.
  3. 가입코드 · 이름 · 이메일 · 비밀번호(8자 이상)를 입력하고 [가입 신청].
  4. 관리자가 승인하면 그때부터 로그인해 점검할 수 있습니다.

주의승인 전에 로그인하면 “가입 승인 대기 중입니다” 안내가 뜹니다. 가입코드가 맞지 않는다고 나오면 관리자에게 현재 코드를 다시 확인하세요(재발급될 수 있습니다).

점검자용

현장에서 QR로 20~30초 만에 점검하기

소화기에 붙은 QR을 휴대폰으로 찍으면 그 소화기 정보가 바로 뜨고, 항목을 체크해 점검을 기록합니다. 인터넷이 없는 지하에서도 점검할 수 있습니다.

오프라인 점검

현황 보기

건물별 점검 완료/미완료 확인

참고점검자는 자신에게 배정된 관리파트의 소화기만 점검할 수 있습니다. 스캔했는데 “권한이 없다”고 나오면 관리자에게 파트 배정을 요청하세요.

2QR 점검 방법 가장 중요

QR 스캔→ 정보 확인→ 항목 체크→ (사진)→ 점검완료
  1. QR 스캔 화면에서 [카메라 시작]을 누릅니다.
  2. 권한을 물으면 [허용] (처음 한 번만).
  3. 소화기의 QR을 사각형 안에 비춥니다. 인식되면 자동으로 점검 화면으로 넘어갑니다.
  4. 상단 상자에서 관리번호·위치·종류·제조일·최근 점검일이 내가 점검할 소화기가 맞는지 확인합니다.
  5. 점검 항목을 체크(아래 참고)하고, 필요하면 사진과 이상 내용을 입력합니다.
  6. 맨 아래 [점검완료] → 완료 화면에서 [다음 소화기 스캔]으로 반복합니다.

팁QR이 잘 안 잡히면 소화기에서 10~20cm 떨어뜨리고, 밝은 곳에서 천천히 비추세요.

주의점검은 반드시 소화기에 부착된 QR을 직접 스캔해야 시작됩니다. 라벨이 손상·오염돼 스캔이 안 되면 관리자에게 라벨 재발급을 요청하세요.

3점검 항목 (점검사항 6가지 + 기타사항)

관리대장의 점검사항 6가지와 기타사항을 확인합니다. 처음에는 모두 “정상”으로 체크되어 있습니다. 문제가 있는 항목만 체크를 눌러 해제하세요.

항목확인 내용
약제방출 정상약제가 방출된 흔적 없이 그대로 채워져 있는가
약제응고 정상흔들어 보았을 때 약제가 굳지 않고 움직이는가
게이지상태 정상압력계 바늘이 초록색(정상) 범위에 있는가
손잡이상태 정상손잡이·안전핀·봉인줄이 손상 없이 붙어 있는가
호스상태 정상호스에 균열·막힘·노후·이탈이 없는가
호스걸이 정상호스가 걸이에 제대로 꽂혀 있는가
기타사항 정상위 6가지로 분류되지 않는 그 외 이상(외관 손상, 설치 위치 이탈 등)이 없는가

팁앞의 6가지 항목은 관리대장(엑셀)의 “점검사항” 칸에 그대로 들어갑니다. 체크를 유지하면 O, 체크를 풀면 X 로 표시됩니다.

주의하나라도 체크를 해제하면 결과가 이상 으로, 모두 체크돼 있으면 정상 으로 저장됩니다. 이상이 있으면 아래 이상(불량) 내용 칸에 구체적으로 적어 주세요 — 관리자의 조치필요 목록·관리대장에 그대로 전달됩니다.

4사진 촬영 (선택, 최대 5장)

  • 카메라 아이콘 버튼을 누르면 촬영이 열립니다. 사진 아래에 관리번호가 자동으로 새겨집니다.
  • 조치 전·후 등 최대 5장까지 추가할 수 있고, 잘못 찍은 사진은 오른쪽 위 ✕로 삭제합니다.
  • [휴대폰에 저장]으로 내 휴대폰에도 저장 — 아이폰은 공유 메뉴의 “이미지 저장”, 안드로이드는 공유 대상에서 갤러리 선택.

참고이상으로 저장하면 관리자 화면에서 조치필요 로 분류됩니다. 관리자가 조치를 마쳐야 그 달의 점검완료로 최종 집계됩니다. 점검자는 점검만 정확히 기록하면 됩니다.

5점검 현황 보기

  1. QR 스캔 화면 아래 [점검 현황 보기]를 누릅니다.
  2. 건물별로 이번 달 점검이 끝난 소화기와 남은 소화기를 봅니다.
  3. 건물을 누르면 그 건물의 소화기 목록을 자세히 볼 수 있습니다.

6인터넷이 안 될 때 (오프라인)

  1. 인터넷이 끊기면 화면 위에 오프라인 안내 띠가 뜹니다.
  2. 평소처럼 QR을 찍고 점검을 저장합니다 — 휴대폰 안에 임시 저장됩니다.
  3. 인터넷이 되는 곳으로 나오면 자동으로 동기화됩니다.

주의오프라인 점검 뒤에는 인터넷 되는 곳에서 앱을 한 번 열어 동기화 대기 건수가 0이 됐는지 확인하세요. 동기화 전 앱 데이터 삭제·휴대폰 초기화 시 임시 점검이 사라질 수 있습니다.

7한 장 요약

  1. 아이콘 실행 → 로그인
  2. [카메라 시작] → 소화기 QR 찍기
  3. 소화기 정보 확인 → 문제 있는 항목만 체크 해제 (5개)
  4. (필요시) 사진 촬영·이상 내용 입력 → [점검완료]
  5. [다음 소화기 스캔]으로 반복

3관리파트란?

한 사업장 안에서 소화기를 나눠 관리하는 조직 단위입니다 (예: 공사/소방, 기상/AQ/생명푸드 등).

  • 각 파트에는 코드(관리번호 앞자리)와 이름이 있습니다.
  • 관리번호는 파트 코드로 시작합니다 — 공사-1-1-1, 소방-1-1-1.
  • 건물·층은 파트끼리 공용이지만, 파트가 다르면 소화기 번호는 1부터 따로 매겨집니다.
  • 관리파트는 권한을 나누는 기준이기도 합니다 (특정 파트만 담당하도록 배정 가능).

4사업장·건물 관리

사업장을 누르면 그 사업장의 관리파트 → 건물 → 층 → 차량 구조를 관리합니다.

관리파트 추가/수정 시스템관리자만

  1. 사업장 상세의 관리파트 영역에서 [관리파트 추가].
  2. 코드(전체에서 유일)와 이름을 입력해 저장. 기존 파트는 옆의 수정 아이콘으로 변경.

주의소속 소화기가 있는 파트의 코드를 바꾸면 그 파트 소화기들의 관리번호가 모두 자동 재계산됩니다. 부착된 QR과 달라질 수 있으니, 화면 안내에 따라 QR 재출력 여부를 확인하세요. (변경 전 번호는 이력으로 보존돼 옛 QR도 계속 연결됩니다)

건물·층·차량

  • 건물 추가 — 건물 번호·이름 입력.
  • 층 추가/순서 — 층 코드(예: 1, 2, 0=지하, R=옥상), 층 선택 후 ▲▼로 순서 변경.
  • 차량 추가 — 번호·번호판·차종·관리부서 입력 (차량도 건물 소속).

5소화기 등록

  1. 위치 유형: 건물 또는 차량
  2. 사업장 선택
  3. 관리파트 선택 — 관리번호 앞자리가 됩니다 (예: 공사-1-1-1)
  4. 건물 → (건물) 층 / (차량) 차량 선택
  5. 설치 위치 입력 (예: 출입구 옆 소화전함)
  6. 관리번호 끝자리(선택) — 비우면 자동 부여
  7. 종류·용량·제조년월(연·월)·제조번호·내용연수 입력 → [등록]

참고관리번호(전체)는 자동 생성됩니다 — 건물 {파트}-{건물}-{층}-{번호}, 차량 {파트}-{건물}-차-{번호}.

제조일은 연·월만 입력하며 그 달 1일로 저장됩니다(교체예정일 계산 기준). 끝자리가 중복되면 저장이 막히니 비워서 자동 부여되게 하세요.

6점검현황 · 이상사항 조치

상단 사업장 버튼으로 대상 사업장을 고르면 화면 전체가 그 사업장 기준으로 바뀝니다. 아래 4개 탭으로 목록을 봅니다.

탭뜻
이번달 미점검이번 달에 아직 점검되지 않은 소화기
조치필요이상으로 점검됐지만 아직 관리자가 조치하지 않은 소화기
조치완료이상이었으나 조치를 마친 소화기 (불량항목·내용·조치내용·조치일)
점검완료이번 달에 정상으로 점검완료된 소화기

이상사항 조치하기 (조치필요 → 조치완료)

  1. 조치필요 탭에서 불량항목과 불량내용(점검자가 적은 내용)을 확인합니다.
  2. 행 오른쪽 [조치] 버튼을 누릅니다.
  3. 조치내용(예: “압력 부족으로 신품 교체”)을 입력하고 [조치완료].
  4. 그 소화기는 조치완료 탭으로 이동하고 그 달의 점검완료로 집계됩니다.

참고점검 기록 자체는 수정·삭제되지 않고 그대로 보존됩니다(감사 무결성). 매달 1일이면 목록은 그달 점검 기준으로 다시 시작하고, 지난달 조치 기록은 목록에서 빠지되 보존됩니다.

7관리대장(엑셀) 다운로드

  1. 점검현황에서 대상 사업장 버튼을 먼저 누릅니다.
  2. 오른쪽 위 [○○○ 관리대장] 버튼을 누릅니다.
  3. 그 사업장의 관리대장 엑셀(.xlsx)이 다운로드됩니다.

표지(점검일자·점검자 수기란 + 동·층별 보유현황표)와 점검대장(위치·종류·제조일·점검사항 6개(O/X)·최근점검일·점검결과·불량항목·불량내용·조치내용·이번달상태 등)이 담깁니다.

팁점검사항 칸(약제방출·약제응고·게이지상태·손잡이상태·호스상태·호스걸이)은 점검자가 체크를 유지하면 O, 체크를 풀면 X 로 찍힙니다. 조치를 완료하면 X 였던 칸이 O 로 바뀝니다. 아직 점검하지 않았거나 2026-07-27 이전에 한 점검은 빈칸입니다.

8점검자 배정

점검자에게 내가 맡은 관리파트의 점검 권한을 부여하는 화면입니다.

  • 세로축 점검자 × 가로축 부여 가능한 관리파트의 매트릭스입니다.
  • 칸의 체크박스를 켜면 그 점검자가 그 파트의 소화기를 스캔·점검할 수 있습니다 (저장 버튼 없이 즉시 반영).

주의관리자는 자기에게 배정된 범위의 파트만 부여할 수 있습니다. 부여할 파트가 없다고 나오면 시스템관리자에게 담당 배정을 요청하세요.

9사용자 관리 · 가입 승인

점검자 가입코드 발급 · 확인

  1. 사업장/건물 관리 → 사업장 선택 → 맨 위 점검자 가입코드.
  2. 시스템관리자는 [가입코드 발급]로 4자리 코드를 만들고, 관리자는 담당 사업장 코드를 보고 [복사]할 수 있습니다.
  3. 코드가 유출되면 시스템관리자가 [재발급] — 새 코드가 생기고 옛 코드는 즉시 무효가 됩니다(이미 승인된 계정은 영향 없음).

참고코드가 짧은 대신, 같은 곳에서 틀린 코드를 반복해 넣으면 잠시 차단됩니다. 점검자가 “가입 시도가 너무 많다”는 안내를 받으면 10분 뒤 다시 시도하게 하세요.

가입 신청 승인 관리자·시스템관리자

  1. 점검자가 가입코드로 신청하면 사용자 관리 → 가입 승인 대기에 이름·이메일·신청 사업장·신청일이 나타납니다.
  2. [승인] → 그 사업장 전체의 점검 권한이 부여되고 즉시 로그인·점검이 가능합니다. (파트를 하나씩 고를 필요 없음)
  3. [거부] 하면 신청 계정이 삭제됩니다(같은 이메일로 재신청 가능).
  4. 점검자를 잠시 막아야 하면 상태 열의 [활성] 버튼으로 비활성 처리합니다(내 담당 사업장 점검자만, 점검 기록은 보존).

주의승인 전 계정은 로그인해도 “가입 승인 대기 중” 안내만 뜨고 아무 데이터도 열리지 않습니다.

계정 직접 만들기

  1. 관리자: [점검자 추가] → 이름·이메일·임시 비밀번호 + 점검 범위(사업장) 체크. 내가 담당하는 사업장만 보입니다.
  2. 시스템관리자: [새 사용자] → 역할(관리자/점검자)과 담당 사업장까지 지정.
  3. 담당 배정 창에서 범위를 지정합니다 — 사업장 전체(현재·미래 모든 파트) 또는 특정 관리파트(그 파트만).

주의일반 관리자에게는 자기 담당 사업장의 점검자만 보이고, 역할 변경·계정 삭제는 할 수 없습니다(시스템관리자 전용).

팁여러 파트로 나뉜 사업장에서 한 담당자에게 특정 파트만 맡기려면 “특정 관리파트” 배정을 쓰세요. 파트를 나누지 않은 사업장은 “사업장 전체”만으로 충분합니다. 시스템관리자 계정은 보호되어 삭제·강등·비활성화가 되지 않습니다.

10기타 메뉴 · 삭제 · 백업

  • 수량 현황 — 사업장별 건물×종류 교차표.
  • 내용연수 관리 — 교체예정일 순. 상태 교체 90일/30일 전 만료 (CO₂·할론 등 내용연수 없는 종류 제외).
  • 사진 관리 — 관리번호별 조회·삭제·ZIP 다운로드.
  • QR Code 관리 — 검색·다중선택 후 라벨 크기 지정, 한 장씩 인쇄. 등록/수정 직후엔 [새로고침] 후 인쇄.
  • 소화기 삭제 — 상세 상단 [삭제] → 관리번호를 정확히 입력해야 활성화.

주의삭제는 되돌릴 수 없고, 점검 이력·사진까지 영구 삭제됩니다. 실제 폐기·철수한 소화기에만 사용하세요. 화면 내 백업/복원 버튼은 없으며, 데이터는 클라우드 자동 백업 + 필요 시 관리대장·사진 ZIP으로 수동 보관합니다.

자주 묻는 질문

  • 로그인이 안 될 때
  • QR이 안 잡힐 때
  • 스캔은 되는데 권한 없음
  • 오프라인·동기화
  • 최신 반영 안 됨
문제 해결

자주 발생하는 오류와 해결 방법

대부분은 ① 인터넷 확인 → ② 앱 새로고침/재실행 → ③ 재로그인 으로 해결됩니다.

Q로그인이 안 돼요

  • 이메일·비밀번호를 다시 정확히(앞뒤 공백·대소문자) 입력하고 인터넷을 확인합니다.
  • "가입 승인 대기 중"이라고 뜨면 아직 승인 전입니다. 사업장 관리자에게 승인을 요청하세요.
  • 그래도 안 되면 관리자에게 계정 활성 상태·비밀번호 재설정을 요청하세요. (비밀번호 찾기 기능은 아직 없음)

QQR이 인식되지 않아요

  • 소화기에서 10~20cm 떨어뜨려 사각형 안에 맞추고, 밝은 곳에서 천천히 비춥니다.
  • “카메라 권한 거부” — 안드로이드: 주소창 자물쇠 → 권한 → 카메라 허용 / 아이폰: 설정 → Safari → 카메라 허용 후 앱 재실행.
  • 라벨이 손상·오염됐으면 관리자에게 라벨 재발급을 요청하세요 (점검은 QR 스캔 필수).

주의아이폰은 사파리로 “홈 화면에 추가”한 앱에서만 카메라가 정상 동작합니다.

Q스캔은 되는데 “권한이 없다”고 나와요 (점검자)

  • 점검자는 배정된 관리파트의 소화기만 점검할 수 있습니다.
  • 관리자에게 점검자 배정 화면에서 해당 파트 권한을 켜 달라고 요청하고, 앱을 새로고침/재로그인하세요.

Q오프라인·동기화가 안 돼요

  • 오프라인이어도 점검은 그대로 진행 — 휴대폰에 임시 저장됩니다. 인터넷 되는 곳으로 이동하면 자동 동기화.
  • 대기 건수가 안 줄면 앱을 완전히 껐다 켜거나 재로그인, 다른 인터넷으로 시도합니다.

주의동기화가 끝나기 전 앱 데이터 삭제·휴대폰 초기화를 하면 임시 점검이 사라질 수 있습니다.

Q방금 등록/수정했는데 목록에 안 보여요

  • 화면을 새로고침합니다 (최대 30초 임시 캐시가 있어 잠깐 옛 값이 보일 수 있음).
  • QR Code 관리 화면은 [새로고침] 버튼을 누릅니다. 그래도 안 보이면 앱을 껐다 켭니다.
