# 소화기 점검 관리 시스템 — 매뉴얼 모음

이 폴더는 사용자 매뉴얼 문서 모음입니다. 목적에 맞는 문서를 여세요.

| 문서 | 대상 | 내용 |
|---|---|---|
| [매뉴얼.html](매뉴얼.html) | 모두 | **한 페이지 통합 매뉴얼** — 설치·점검자·관리자·FAQ를 탭으로 전환(브라우저로 열어 보기) |
| [설치가이드.md](설치가이드.md) | 모두 | 안드로이드/아이폰/PC 설치, 첫 로그인 |
| [사용자매뉴얼.md](사용자매뉴얼.md) | 점검자 | QR 스캔 점검, 사진, 오프라인, 현황 보기 |
| [관리자매뉴얼.md](관리자매뉴얼.md) | 관리자·시스템관리자 | 메뉴별 사용법, 관리파트, 소화기 등록, 이상사항 조치, 관리대장, 점검자 배정, 사용자 관리 |
| [FAQ.md](FAQ.md) | 모두 | 자주 발생하는 오류와 해결 방법 |
| [테스트체크리스트.md](테스트체크리스트.md) | 배포 담당 | 배포/업데이트 후 점검 체크리스트 |
| [images/스크린샷목록.md](images/스크린샷목록.md) | 문서 작성자 | 넣어야 할 스크린샷 파일명 목록 |

> **매뉴얼.html** 은 위 MD 문서들의 내용을 한 페이지로 합쳐 보기 좋게 렌더링한 것입니다(라이트/다크 테마, 모바일 지원). 파일을 더블클릭해 브라우저로 열면 됩니다. 내용의 원본·상세는 각 MD 문서이며, 기능이 바뀌면 **MD를 먼저 갱신한 뒤 HTML에도 반영**하세요.

## 기본 정보

- **버전**: 1.0.4 (2026년 7월 기준)
- **접속 주소**: https://shg-inspector.vercel.app
- **작성일**: 2026-07-26

## 읽는 순서 (처음이라면)
1. **설치가이드** — 휴대폰/PC에 설치하고 로그인
2. 점검자라면 **사용자매뉴얼**, 관리자라면 **관리자매뉴얼**
3. 막히면 **FAQ**

> 스크린샷은 아직 비어 있습니다. `images/스크린샷목록.md` 의 파일명대로 캡처해 `images/` 폴더에 넣으면 매뉴얼의 `[스크린샷: ...]` 자리에 채워집니다.
