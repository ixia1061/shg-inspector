## A. 설치 · 로그인

- [ ] 안드로이드에서 "홈 화면에 추가"로 설치되고 아이콘이 생긴다.
- [ ] 아이폰(사파리)에서 "홈 화면에 추가"로 설치된다.
- [ ] PC(크롬/엣지)에서 접속되고, 설치 아이콘으로 설치된다.
- [ ] 올바른 이메일/비밀번호로 **로그인**이 된다.
- [ ] 잘못된 비밀번호는 **로그인 실패 메시지**가 뜬다.
- [ ] 관리자 로그인 → **대시보드**로 이동한다.
- [ ] 점검자 로그인 → **QR 스캔** 화면으로 이동한다.

## B. 점검자 — QR 점검

- [ ] **[카메라 시작]** 을 누르면 카메라가 켜진다.
- [ ] 카메라 권한 요청이 뜨고 **허용**하면 스캔이 시작된다.
- [ ] 소화기 QR을 비추면 **점검 화면으로 자동 이동**한다.
- [ ] QR 없이 관리번호만으로는 점검 화면에 들어갈 수 없다(점검은 QR 스캔 필수).
- [ ] 배정되지 않은 파트의 소화기를 스캔하면 점검 화면이 열리지 않는다(권한 없음).
- [ ] 점검 화면에 관리번호·위치·종류·제조일·제조번호·최근점검이 맞게 나온다.
- [ ] 점검 항목 **7개(약제방출·약제응고·게이지상태·손잡이상태·호스상태·호스걸이·기타사항)** 가 **처음에 모두 정상(체크)** 되어 있다.
- [ ] 항목 체크를 해제하고 저장하면 결과가 **"이상"** 으로 저장된다.
- [ ] 모두 정상으로 저장하면 **"정상"** 으로 저장된다.
- [ ] **이상(불량) 내용**을 입력해 저장하면 상세/조치필요 목록/관리대장에 반영된다.
- [ ] 카메라 버튼으로 사진을 찍으면 **관리번호 워터마크**가 새겨진다.
- [ ] 사진을 5장까지 추가할 수 있고, 6장째는 막힌다.
- [ ] 사진 ✕로 삭제가 된다.
- [ ] **[휴대폰에 저장]** 으로 사진이 갤러리에 저장된다.
- [ ] **[점검완료]** 후 완료 화면이 뜬다.
- [ ] **[다음 소화기 스캔]** 으로 스캔 화면으로 돌아간다.
- [ ] **[점검 현황 보기]** → 건물별 현황이 보인다.

## C. 점검자 — 오프라인/동기화

- [ ] 인터넷을 끈 상태에서 오프라인 안내 띠가 뜬다.
- [ ] 오프라인에서 점검을 저장할 수 있다.
- [ ] 인터넷을 다시 켜면 **자동 동기화**되어 서버에 반영된다.
- [ ] 동기화 완료 후 관리자 화면에 그 점검이 나타난다.

## D. 관리자 — 조직/소화기

- [ ] 대시보드 요약 카드(전체/이번달 점검·미점검/교체예정/만료/최근이상)가 나온다.
- [ ] (시스템관리자) 사업장 추가/수정이 된다.
- [ ] (시스템관리자) 사업장 상세에서 **관리파트 추가/수정**(코드·이름)이 된다.
- [ ] 소화기가 있는 파트의 **코드를 변경**하면 QR 재출력 경고 후, 그 파트 소화기 관리번호가 자동 재계산된다.
- [ ] 건물·층·차량을 추가할 수 있다.
- [ ] 층 순서를 ▲▼로 바꿀 수 있다.
- [ ] **소화기 등록**: 위치→사업장→**관리파트**→건물→층/차량→종류→용량→제조년월(연·월)→제조번호→내용연수 입력 후 등록된다.
- [ ] 등록 시 선택한 **관리파트 코드가 관리번호 앞자리**로 반영된다(예: `공사-1-1-1`).
- [ ] 제조년월을 `2026-12`처럼 입력하면 저장되고, **그 달 1일**로 저장된다.
- [ ] 관리번호 끝자리를 비우면 **자동 부여**된다.
- [ ] 관리번호 끝자리를 중복 지정하면 저장이 막힌다.

## E. 관리자 — 검색/현황/대장

- [ ] 소화기 검색이 **관리번호**로 된다.
- [ ] 소화기 검색이 **제조번호**로 된다.
- [ ] 소화기 검색이 **위치(한글: 건물/층/설치위치)** 로 된다.
- [ ] 사업장/상태 필터가 동작한다.
- [ ] 점검현황에서 **사업장 버튼**을 누르면 그 사업장만 표시된다.
- [ ] **미점검 / 조치필요 / 조치완료 / 점검완료** 4개 탭이 올바르게 나뉜다.
- [ ] 이상으로 점검된 소화기가 **조치필요** 탭에 불량항목·불량내용과 함께 나온다.
- [ ] **[조치]** 로 조치내용을 입력해 완료하면 **조치완료** 탭으로 이동하고, 점검률·대시보드 완료에 반영된다.
- [ ] 정상 점검완료 소화기는 **점검완료** 탭에만 나온다(조치필요/조치완료와 섞이지 않음).
- [ ] **관리대장(엑셀)** 이 선택 사업장 기준으로 다운로드된다.
- [ ] 관리대장 표지(점검일자·점검자란, 보유현황표)와 점검대장이 채워져 있다.
- [ ] 관리대장에 **불량항목·불량내용·조치내용·이번달상태**가 반영된다.
- [ ] 관리대장 **점검사항 6개 칸**에 O/X가 찍힌다(체크 유지=O, 해제=X, 미점검=빈칸).
- [ ] **조치완료**한 소화기는 점검사항 칸의 X가 **O 로 바뀐다**(불량항목·조치내용은 그대로 남음).
- [ ] 관리대장 최근점검일이 **한국 시간 기준**으로 맞다.

## F. 관리자 — 기타 메뉴

- [ ] 수량 현황이 사업장별 교차표로 나온다.
- [ ] 내용연수 관리에 교체예정/만료가 나온다.
- [ ] 사진 관리에서 사진 조회·삭제·ZIP 다운로드가 된다.
- [ ] 통계에 건물별 점검률·점검자별 실적이 나온다.
- [ ] QR Code 관리에서 다중 선택 후 라벨이 한 장씩 인쇄된다.

## G. 관리자 — 삭제/권한

- [ ] 소화기 상세에서 **관리번호 입력** 후 삭제가 된다.
- [ ] 삭제 시 그 소화기의 점검 이력·사진도 함께 사라진다.
- [ ] 일반 관리자에게는 **사용자 관리 메뉴가 안 보인다.**
- [ ] (시스템관리자) 사용자 추가·역할 변경이 된다.
- [ ] (시스템관리자) 담당 범위를 **사업장 전체** 또는 **특정 관리파트**로 배정할 수 있다.
- [ ] 사업장 전체 배정 시 그 사업장의 모든 파트 데이터가 보인다.
- [ ] 특정 파트 배정 시 **그 파트 데이터만** 보인다(다른 파트는 안 보임).
- [ ] 사용자 관리에서 점검자의 **[범위 변경]** 으로 사업장을 체크·해제해 점검 권한을 바꿀 수 있다.
- [ ] 범위 변경 창에 **내가 담당하는 사업장만** 나온다.
- [ ] 시스템관리자가 사업장 전체로 배정한 곳은 **전체 배정됨**으로 잠겨 해제되지 않는다.
- [ ] 내 계정에서 비밀번호를 바꿀 수 있다.

## G-2. 점검자 가입 신청 · 승인

- [ ] (시스템관리자) 사업장 상세에서 **가입코드를 발급**하고 복사할 수 있다.
- [ ] 로그인 화면의 **[점검자이신가요? 가입 신청]** 으로 가입 화면이 열린다.
- [ ] 올바른 가입코드로 신청하면 **"가입 신청이 접수되었습니다"** 안내가 나온다.
- [ ] **잘못된 가입코드**로 신청하면 한국어 안내가 나오고 계정이 만들어지지 않는다.
- [ ] **이미 가입된 이메일**로 신청하면 "이미 가입된 이메일입니다" 안내가 나온다.
- [ ] 승인 전에 로그인하면 **"가입 승인 대기 중"** 안내가 뜨고 아무 화면도 열리지 않는다.
- [ ] 신청이 그 사업장 관리자의 **사용자 관리 → 가입 승인 대기**에 나타난다.
- [ ] **다른 사업장 관리자**에게는 그 신청이 보이지 않는다.
- [ ] 승인하면 그 점검자가 로그인해 **신청 사업장의 소화기**를 점검할 수 있다(파트를 하나씩 고르지 않아도 된다).
- [ ] (관리자) **[점검자 추가]** 의 점검 범위가 **사업장 체크박스**로 나오고, **내가 담당하는 사업장만** 보인다.
- [ ] 모든 사업장을 담당하는 관리자는 사업장 전부가, 한 곳만 담당하는 관리자는 그 하나만 보인다.
- [ ] (관리자) 자기 사업장 점검자를 **[활성] ↔ [비활성]** 으로 바꿀 수 있다.
- [ ] 비활성된 점검자는 로그인해도 아무 화면이 열리지 않고, 다시 활성하면 정상 사용된다.
- [ ] (관리자) 자기 사업장 점검자를 **삭제**할 수 있다.
- [ ] **점검 이력이 있는 점검자**는 삭제되지 않고 "점검 이력이 ○건 있어 삭제할 수 없습니다" 안내가 나온다.
- [ ] 관리자에게는 점검자 행에 **역할 변경** 셀렉트와 **담당 배정** 버튼이 보이지 않는다.
- [ ] **거부**하면 목록에서 사라지고, 같은 이메일로 다시 신청할 수 있다.
- [ ] **재발급** 후 옛 가입코드로 신청하면 거부된다.
- [ ] (관리자) **[점검자 추가]** 로 만든 계정은 바로 로그인·점검이 된다.
- [ ] (시스템관리자) **[새 사용자]** 로 만든 관리자/점검자 계정도 바로 로그인이 된다.
- [ ] 일반 관리자에게는 **자기 사업장 점검자만** 보이고, 역할 변경·삭제 버튼이 없다.

## G-3. 관리대장 월별 다운로드

- [ ] 점검현황의 대장 버튼에는 월 선택이 없고, 받으면 진행 중인 점검 기준 대장이 나온다.
- [ ] 사이드바에 **관리대장** 메뉴가 있고, 점검 기록이 있는 달이 최신 순으로 나온다.
- [ ] 각 달에 **점검 대수 / 전체 대수(점검률)** 가 표시되고 이번 달에는 **진행 중** 배지가 붙는다.
- [ ] 담당 사업장이 여러 곳이면 사업장 버튼으로 나뉘고, **담당 밖 사업장은 안 보인다**.
- [ ] 지난 달을 받으면 파일명에 그 달이 붙고(`..._2026-07.xlsx`), 표지 제목과 상태 컬럼명에도 그 달이 표시된다.
- [ ] 지난달 대장의 **점검일·점검자·O/X·불량내용·조치내용**이 그 달에 한 점검과 일치한다.
- [ ] 그 달에 점검하지 않은 소화기는 **미점검**으로 나오고 점검 관련 칸이 비어 있다.
- [ ] 그 달 이후에 다시 점검한 소화기도 **그 달 점검 내용**으로 나온다(이후 점검이 섞이지 않음).
